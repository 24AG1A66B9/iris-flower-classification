# 🌸 Iris Flower Classification

A Machine Learning project that classifies Iris flowers into **Setosa, Versicolor, and Virginica** based on their sepal and petal measurements.

## 📌 Project Overview

This project uses Machine Learning to predict the species of an Iris flower from four measurements:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The project uses the **Iris dataset** available in Scikit-learn and a **Logistic Regression** classification model.
